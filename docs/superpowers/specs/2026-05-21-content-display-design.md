# Electronic Music Documentary Atlas Content Display Design

Date: 2026-05-21

## Purpose

This design defines the public-facing content rules for the electronic music documentary site. The site should read as a curated film archive, not as a database dump or generic resource list. Public pages should prioritize film covers, original titles, clear routes, reliable descriptions, and watch links with source context.

## Confirmed Decisions

### Public Grade Language

Do not use internal `S / A / B` or `A-list` language as the main public copy.

Use reader-facing labels:

- `核心影片` for internal `S`
- `重要影片` for internal `A`
- `延伸片目` for internal `B`

Internal grade codes can remain in data and tests, but should not be prominent in public UI.

### Title Display

Use original titles first.

Only show a Chinese title when it is mature, common, and not forced. If a film does not have a reliable Chinese title, do not invent one for public display.

Recommended card pattern:

- Primary title: original title
- Secondary title: mature Chinese title, if available

### Main Collection Boundary

The home wall and main library should focus on films that directly explain electronic music history through instruments, studios, scenes, people, genres, technologies, cities, or performance cultures.

`How Music Got Free` should move out of the main electronic music collection. It can appear under a related `媒介产业延伸` area because it is primarily about MP3, file sharing, and music industry history.

### Extended Films

`B` films should not appear in the home wall or main library.

They should live in a separate `延伸片目` area. This lets the site grow without diluting the main archive.

### Home Film Wall

The PC home film wall should scale covers up by about 25 percent from the current version. The goal is more visual presence while keeping enough air between covers.

The home wall remains a first-screen visual entry. It should keep text secondary and avoid large statistic panels.

### Curated Routes

Routes should be hand-curated, not generated by broad keyword matching.

Each film should appear in at most:

- one main route
- one auxiliary route

This prevents broad overview films such as `Modulations: Cinema for the Ear` from appearing everywhere just because they touch many topics.

Recommended route set:

- `入门路径`: broad first-watch path from instrument, studio, dancefloor, techno, and sampling.
- `机器与录音室`: electronic instruments, synthesizers, tape, sound labs, and studio-as-instrument history.
- `舞池与城市`: disco, house, techno, rave, Detroit, New York, Chicago, UK rave, and club culture.
- `欧洲线索`: Krautrock, synth-pop, Germany/Berlin, Belgium, and European electronic identity.
- `女性先锋`: women electronic music pioneers and obscured authorship lines.

`媒介产业` should be an extension topic, not a main route.

### Library Filtering

Replace database-like dropdown filters with a film-library style tag browser.

Remove prominent public filters for:

- `地区`
- `状态`
- `等级`

Keep a search field for film title, people, city, technology, genre, or topic.

Below search, show multi-row clickable tag chips.

Suggested tag groups:

- Routes: `入门路径`, `机器与录音室`, `舞池与城市`, `欧洲线索`, `女性先锋`
- Topics: `合成器`, `鼓机`, `采样`, `Dub`, `House`, `Techno`, `Rave`, `Krautrock`, `BBC Radiophonic Workshop`, `Detroit`, `Berlin`, `NYC`
- Availability: `有观看渠道`, `免费可看`, `B站可看`, `馆藏/平台`

Multi-select tag behavior should use `OR` logic. Selecting `Techno` and `House` should show films matching either tag, because the site is for browsing and discovery.

Film cards should show at most four tags:

- one route tag when relevant
- two or three concrete topic tags

### Film Detail Card

Detail cards should stay concise and professional.

Include:

- original title
- mature Chinese title, if available
- year
- director
- runtime
- country and language
- 120-180 Chinese character description
- watch channels
- sources

Do not include:

- `策展定位`
- `观看说明`
- notes or miscellaneous remarks

### Description Source Rules

Descriptions should be rewritten from reliable professional sources, not from subjective placeholder copy.

Source priority:

1. official film site, distributor, broadcaster, or platform page
2. festival and institution pages, such as IDFA, BFI, Goethe-Institut, NFB, BBC
3. streaming platform pages
4. IMDb, TMDb, Letterboxd, and similar databases only as auxiliary metadata sources

Descriptions should be Chinese, roughly 120-180 characters, and factual rather than promotional.

### Watch Channel Rules

Search Bilibili for watchable links during data refinement.

Bilibili user-uploaded videos may be shown, but must be labeled as `用户上传 / 授权待核验`.

Watch channels should distinguish:

- official
- legitimate platform
- institutional collection
- free but unverified
- Bilibili watchable
- offline or festival only
- no reliable channel yet

Free watchability must not imply public screening permission.

## Data Model Implications

The current `documentaries.json` can keep internal fields, but the public renderer needs presentation fields or helpers:

- public grade label
- display title and optional translated title
- main route id
- auxiliary route ids
- public tags
- collection visibility: main, extended, related
- watch channel display label and reliability label
- description source reference

This can be implemented either by extending the JSON data directly or by adding a small presentation mapping layer.

## Implementation Plan Outline

1. Add presentation helpers for grade labels, title display, and compact public tags.
2. Update homepage copy from `A 类` language to `核心/重要` language.
3. Scale the PC home film wall covers by about 25 percent.
4. Move `How Music Got Free` out of the main collection and into a related media-industry extension bucket.
5. Change route generation from keyword matching to manual route definitions.
6. Replace dropdown filters with search plus tag chips.
7. Update film cards to show original-title-first and a maximum of four tags.
8. Simplify detail cards to basic metadata, description, watch channels, and sources.
9. Add data work tasks for professional descriptions and Bilibili watch-link review.
10. Add tests for public labels, route membership limits, tag OR filtering, and main-vs-extension visibility.

## Open Data Work

The implementation can proceed structurally before all descriptions are rewritten, but final content quality requires a separate data pass:

- professional descriptions for all main films
- Bilibili watch-link search and reliability labeling
- mature Chinese title review
- route membership review for each main film
- `B` and related-topic extension placement
